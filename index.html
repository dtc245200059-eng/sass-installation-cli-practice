[Thực Hành] Cài Đặt SASS Bằng npm & SASS CLI

Báo cáo kết quả và hướng dẫn thực hành kiểm tra môi trường Node.js, cài đặt Dart SASS qua npm/CLI, và thực hiện biên dịch SCSS sang CSS đơn tệp & đa thư mục với SASS Compiler.

Node.js Environment:
v24.19.0 (Active)
npm Package Manager:
v11.17.0 (Active)
Dart SASS Compiler:
v1.105.1 (Active)
100% SẴN SÀNG
Bước 1, 2 & 3 🟢

Kiểm tra & Cài đặt Node.js / npm

Kiểm tra sự hiện diện của Node.js và npm trên máy tính trước khi tiến hành cài đặt SASS.

bash / powershell
# Kiểm tra phiên bản Node.js
node -v
> v24.19.0

# Kiểm tra phiên bản npm
npm -v
> 11.17.0
Bước 4 📦

Cài đặt SASS Toàn Cục bằng npm

Sử dụng npm với cờ -g để cài đặt SASS ở phạm vi toàn hệ thống.

terminal
# Cài đặt global package
npm install -g sass

# Xác nhận phiên bản
sass --version
> 1.105.1 compiled with dart2js 3.13.5
Bước 5 ⚡

Cài đặt SASS CLI Không Cần npm

Tải trực tiếp bản phát hành độc lập từ GitHub Releases và thêm vào biến môi trường PATH.

releases info
# Nguồn tải trực tiếp:
github.com/sass/dart-sass/releases

# Giải nén & thêm vào PATH:
C:\Program Files\SASS\sass.bat
sass --version
Bước 6 📄

Biên dịch SCSS sang CSS Đơn Tệp

Chuyển đổi file SCSS chỉ định thành CSS sẵn sàng sử dụng trên website.

sass cli
# Cú pháp biên dịch 1 file:
sass styles.scss styles.css

# Đã tạo thành công:
✓ styles.css (2.7 KB)
✓ styles.css.map
Bước 7 👁️

Kích hoạt Chế độ Theo dõi (Watch)

Tự động phát hiện thay đổi trong mã SCSS và tức thì biên dịch lại CSS.

watch mode
# Cú pháp theo dõi tự động:
sass styles.scss styles.css --watch

Sass is watching for changes. Press Ctrl-C to stop.
Bước 8 📁

Biên dịch Nhiều Tệp Theo Thư Mục

Ánh xạ toàn bộ thư mục đầu vào scss/ sang thư mục đầu ra css/.

multi-file compile
# Biên dịch toàn bộ folder:
sass scss/:css/

# Hoặc kết hợp watch:
sass scss/:css/ --watch
✓ scss/main.scss -> css/main.css
✓ scss/page.scss -> css/page.css

Xử lý Lỗi "Set-ExecutionPolicy" trên Windows (Mục 9)

Khi chạy lệnh npm hoặc sass trên Windows PowerShell và gặp thông báo chặn kịch bản thực thi: cannot be loaded because running scripts is disabled on this system.

powershell (run as administrator)
# Mở PowerShell với quyền Quản trị (Admin) và chạy:
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
# Hoặc:
Set-ExecutionPolicy Unrestricted

✔ Lệnh này cấp quyền chạy script hợp lệ trên hệ thống Windows, giúp các lệnh SASS CLI hoạt động trơn tru.
